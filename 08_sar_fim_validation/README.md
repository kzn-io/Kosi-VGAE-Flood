# SAR/FIM validation module

This folder contains the five-event (2020–2024) VGAE-only LOBO validation
script, the journal-figure generator, supplied validation tables/workbook,
and ten supplied figures.

Start with `docs/METHOD_AND_REPRODUCTION.md`. Configure the local Windows
paths at the top of each script before running. The validation script uses
only the >=1% and >=5% flood-fraction targets and preserves the existing K=10
cluster assignments.
